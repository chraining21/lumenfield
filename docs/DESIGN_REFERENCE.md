# 參考網站分析（DESIGN_REFERENCE）

> 版本：v0.1（階段 2 草案）
> 參考：日光照明 artlight.com.tw（2026-11-03 瀏覽，桌機 1440px）
> 用途：決定線框（2-3）與視覺風格（2-4）要借鏡什麼、避開什麼。

---

## 1. 對方是什麼樣的網站

- 照明**設計顧問**公司，網站純作品展示，**沒有產品型錄與詢價**。
- 頁面：首頁、關於（含創辦人、沿革、部門、合作對象）、服務項目、作品集（8 個分類）、得獎、最新消息、聯絡。
- 技術：傳統 PHP 網站，頁尾版權 2018。

## 2. 觀察到的設計手法

| 面向 | 做法 |
|---|---|
| 主視覺 | 首頁全幅夜景照片輪播；中央一行大字標語＋一行字距拉很開的小字副標 |
| 色彩 | 黑、白、灰為主；**橘色**作為唯一強調色，用量極少（標題的一個字、輪播指示點） |
| 字體 | 英文 Roboto／Muli；中文靠系統字（微軟正黑體） |
| 裝飾 | 細橫線（——）當分隔與標籤前綴；大型淺灰英文浮水印字（如背景的「ABOUT」） |
| 導覽列 | 透明疊在主視覺上，捲動後收合；選單有多層下拉 |
| 首頁作品 | 左右交錯排列（圖左字右、圖右字左），每個作品配大標題＋小字英文標籤（PROJECT YEAR — PROJECT NAME） |
| 作品集列表 | 滿版兩欄、圖片無間距；**滑鼠移上才顯示**案名與年份；右下角固定顯示目前分類與件數（10 / 10） |
| 作品詳細 | 上方大圖＋案名＋麵包屑，下方三欄縮圖、Back Page、上一個／下一個作品 |
| 頁尾 | 深灰底，Logo、簡介、聯絡資訊、地址 |
| 進場 | 首次進站有一段全黑畫面（載入／過場） |

## 3. 借鏡（適合明野）

1. **夜景照片當主角**：明野案例多為燈節、橋梁、古蹟夜間照明，夜景照片天生適合，「暗底襯光」直接表達照明公司的本業。
2. **克制的強調色**：全站黑白灰，只用一個強調色點綴。明野可用**暖琥珀色**（呼應 2700K 暖光）作為品牌色。→ 2-4 決定
3. **大量留白＋細線**：細橫線、小字英文標籤營造專業設計感，成本低、效果好。
4. **首頁作品交錯排列**：比單純格狀更有「作品集」敘事感。
5. **作品集滿版圖片牆**：圖片本身就是內容，無間距排列有沉浸感。
6. **作品詳細的上一個／下一個**：讓訪客連續瀏覽作品。

## 4. 避開（對方的缺點）

| 問題 | 明野做法 |
|---|---|
| 文字太小、對比太低（淺灰小字），中文尤其難讀 | 內文至少 16px，符合 WCAG AA 對比度 |
| 案名**只在滑鼠移上時出現**，手機沒有 hover 就看不到 | 手機版直接顯示案名；桌機 hover 只做加強效果 |
| 作品詳細資訊很少（只有案名） | 明野有年份、地點、分類、介紹，完整呈現 |
| 中文字體依賴系統字，Mac／手機顯示不一致 | 使用網頁字型（如 Noto Sans TC），全平台一致 → 2-4 決定 |
| 多層下拉選單 | 主選單一層，5 個項目 |
| 進站全黑等待畫面 | 不做長時間 preloader，內容優先顯示，動畫在內容出現後才跑 |
| 舊案例照片解析度低 | 圖片統一處理尺寸與格式（WebP），階段 7 優化 |

## 5. 明野與日光的差異（設計必須額外處理）

| 明野獨有 | 設計重點 |
|---|---|
| **產品型錄、規格表、檔案下載** | 需要易讀的規格表與清楚的下載按鈕；建議產品區用**淺色底**，閱讀規格比較輕鬆 |
| **詢價清單** | 導覽列常駐詢價清單圖示與件數；加入時要有明確回饋 |
| **台灣地圖** | 暗底地圖上有作品的縣市「亮起來」，與夜景風格一致，也是最適合放創意動畫的地方 |
| 兩種用戶（設計師／採購） | 首頁主視覺同時提供「看作品」「看產品」兩個入口 |
