# 網站地圖與頁面內容（SITEMAP）

> 版本：v0.1（階段 2 草案）
> 依據：`docs/SPEC.md`、`docs/DATA_MODEL.md`
> 本文件只定義「每頁放什麼」；版面排列見線框（2-3），視覺見 DESIGN_SYSTEM（2-4），動畫見 ANIMATIONS（2-5）。

**資料來源代號**
- `msg`：翻譯檔 `frontend/messages/*.json`（固定文案）
- `products` / `projects` / `categories`：假資料 `frontend/src/mocks/*`，階段 4 改接 API
- `cart`：瀏覽器 localStorage 的詢價清單

---

## 1. 網址結構

所有前台頁面都帶語系前綴：`/zh-TW/...`、`/en/...`。網址路徑兩語系相同（英文）。

| 頁面 | 網址 | 說明 |
|---|---|---|
| 首頁 | `/[locale]` | `/` 自動導向 `/zh-TW` |
| 關於明野 | `/[locale]/about` | |
| 服務項目 | `/[locale]/services` | 5 項服務在同一頁 |
| 設計案例 | `/[locale]/projects` | 篩選條件放網址參數：`?category=festival&year=2024&county=TW-TNN` |
| 案例詳細 | `/[locale]/projects/[slug]` | |
| 產品列表 | `/[locale]/products` | 網址參數：`?tab=type\|space&category=downlight` |
| 產品詳細 | `/[locale]/products/[slug]` | |
| 詢價清單 | `/[locale]/inquiry` | 送出後在同頁顯示完成畫面 |
| 聯絡我們 | `/[locale]/contact` | |
| 404 | — | 找不到頁面 |
| 後台 | `/admin/...` | 階段 6 設計，不在本文件範圍 |

> 篩選放網址參數：可分享連結、上一頁會保留篩選狀態。

## 2. 全站共用

### 2.1 導覽列（Header）

| 區塊 | 內容 | 來源 |
|---|---|---|
| Logo | 明野照明 / LUMENFIELD，點擊回首頁 | `msg` |
| 主選單 | 關於明野、服務項目、設計案例、產品、聯絡我們 | `msg` |
| 詢價清單 | 圖示 + 件數徽章，點擊前往詢價清單 | `cart` |
| 語言切換 | 中文 / English | `msg` |
| 手機版 | 主選單收合為漢堡選單；詢價清單圖示保持可見 | — |

### 2.2 頁尾（Footer）

| 區塊 | 內容 | 來源 |
|---|---|---|
| 公司資訊 | 公司全名（中英）、電話、傳真、Email、地址 | `msg` |
| 網站連結 | 同主選單 | `msg` |
| 版權 | © 年份 明野照明股份有限公司 | `msg` |

> 公司資訊皆為虛構（電話 02-0000-0000、hello@lumenfield.example），頁尾註明「虛構品牌，作品集展示用」。
