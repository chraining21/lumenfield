## 1. 背景

- **公司**：明野照明（LUMENFIELD），虛構品牌，提供從光環境概念規劃、燈具設計製造到現場安裝施工的一條龍專業照明服務。
- **本專案**：照明公司的產品展示與詢價網站，作為 Mimi 的個人作品集。產品、案例與公司資訊皆為虛構。

## 2. 目標用戶與使用情境

| 用戶 | 主要目的 | 使用情境 |
|---|---|---|
| 室內設計師、建築師 | 找靈感、選型號 | 瀏覽設計案例與產品，比較款式與規格，挑選適用型號 |
| 工程、採購單位 | 看規格、要報價、大量訂購 | 查看詳細規格、下載型錄與 IES/CAD 檔，將多款產品加入詢價清單一次送出 |

## 3. 服務項目

1. **整體燈光設計與光環境規劃**
   針對建築物外觀、室內空間、園區景觀及公共領域，進行照度計算、眩光控制與燈光動態效果設計。
2. **展覽與公共藝術照明**
   大型燈節及裝置藝術、雕塑展品照明。
3. **訂製燈具開發與製造**
   客製化結構、防水防塵等級、特殊光束角及智能控制系統之專用燈具研發製造。
4. **照明工程承造與現場調光**
   現場水電配管、燈具固定與線路整合，夜間由設計師進行試燈與細部調光（Aiming）。
5. **節慶活動與街區造街企劃**
   節慶氛圍營造、歷史老街造街、社區光環境美化之全案企劃與統包執行。

## 4. 功能清單

### 4.1 現階段

- 公司介紹、服務項目、設計案例展示
- 設計案例瀏覽：依案例分類、年份篩選；台灣地圖點選地區查看當地作品
- 產品展示：列表（依分類瀏覽）與詳細頁
- 檔案下載：型錄 PDF、IES/CAD 檔
- 價格顯示：每款產品可設定「公開價格」或顯示「詢價」
- 詢價清單：可加入多款產品並填寫數量，送出後 Email 通知管理者
- 後台：管理產品、查看詢價
- 繁中／英文雙語

## 5. 網站地圖與頁面說明

```
首頁
├── 關於明野
```

## 7. 詢價流程

1. 訪客在產品詳細頁點「加入詢價清單」（**不需登入**）。
2. 可加入多款產品，並在詢價清單頁調整數量或移除。
3. 填寫聯絡資訊後送出。
4. 系統寄 Email 通知管理者。
5. 管理者可在後台查看詢價紀錄。

> 詢價清單的結構需能於遠期演變為購物車／訂單。

## 8. 後台功能

- 產品：新增、修改
- 案例：新增、修改（2026-11-03 加入）
- 詢價：查看
- 介面只有中文，網址固定 `/admin`（不帶語系前綴）；產品、案例資料仍有中英文欄位（2026-11-03 決定）
- 開發順序：後台前端先以假資料完成，再做後端（2026-11-03 決定）

**存取與安全**
- 後台網址：與前台同站，路徑 `/admin`。
- 後台需登入；權限一律由後端 API 驗證（`/api/admin/**` 需管理者身分），前端隱藏網址不視為安全措施。
- 後台頁面不被搜尋引擎索引。

> 細節待討論（見第 10 節）。

## 9. 非功能需求

- **雙語**：繁中 + 英文；資料模型從第一天支援雙語，網址區分語系。
- **RWD**：桌機、平板、手機皆可正常瀏覽。
- **SEO**：頁面需可被搜尋引擎索引（伺服器端產生 HTML）。
- **設計風格**：專業公司感、偏作品展示、有創意；參考 artlight.com.tw（日光照明）。
- **動畫**：具體動畫清單待補充；設計階段預留動畫位置。
- **技術**：前端 Next.js（App Router、TypeScript、Tailwind CSS、next-intl、Motion/GSAP）；後端 Spring Boot。
- **開發策略**：前端以假資料先行，可完整展示後，再依序接上資料模型 → 產品 API → 詢價 → 後台。部署最後討論。
